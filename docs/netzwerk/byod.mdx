# Eigene Geräte und BYOD-Netzwerke

Mit der Modernisierung wurden auch wichtige Sicherheitsmechanismen im Netzwerk
umgesetzt. Wichtig vorweg: Diese Maßnahmen bedeuten **nicht**, dass grundsätzlich
keine eigenen Geräte mehr verwendet werden können.

## MAC-Adressfilter für geschützte Bereiche

Zu den neuen Sicherheitsmaßnahmen gehört unter anderem ein **MAC-Adressfilter**.
Dieser sorgt dafür, dass bestimmte Netzwerkbereiche nur von Geräten genutzt
werden können, deren Hardware-Adresse zuvor freigegeben wurde.

Das bedeutet: Einzelne Geräte der Stadt oder Schule erhalten unter Umständen
zunächst keinen Zugriff auf bestimmte Netzwerkbereiche, wenn sie noch nicht
freigegeben wurden.

In diesem Fall erstellen Sie einfach ein [Ticket](../support/ticket-erstellen.mdx).
Die Freischaltung wird dann schnellstmöglich geprüft und bearbeitet. Auch beim
[Ermitteln der MAC-Adresse](../support/mac-adresse-ermitteln.mdx) helfen wir
gerne weiter – per Ticket oder telefonisch.

## Warum manche Bereiche besonders geschützt sind

Es gibt Netzwerkbereiche, die besonders abgesichert werden müssen. Dazu gehören
zum Beispiel Bereiche, in denen interne Server oder sensible Daten genutzt
werden. Auch wenn der Datenverkehr grundsätzlich verschlüsselt ist, muss das
Netzwerk selbst zusätzlich geschützt werden.

## Separate BYOD-Netzwerke

Für private oder eigene Geräte stehen daher eigene **BYOD-Netzwerke** zur
Verfügung („Bring Your Own Device“ – bring dein eigenes Gerät mit).

So können Sie Ihr eigenes Notebook, Tablet oder Smartphone nutzen, ohne dass die
besonders geschützten Bereiche des Schulnetzes berührt werden.

:::info[Kurz gesagt]
Eigene Geräte ja – aber über das dafür vorgesehene BYOD-Netz. Für den Zugriff
auf geschützte Bereiche ist eine vorherige Freigabe nötig.
:::
