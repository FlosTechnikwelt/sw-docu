# Wichtige Daten sicher speichern

Im Zuge der Modernisierung möchten wir auf einen Punkt hinweisen, der im
Schulalltag leicht untergeht, aber wichtig ist: **Wo werden eigentlich meine
Daten gespeichert?**

Private Daten, Abrechnungsdaten oder personenbezogene Informationen sollten
möglichst **nicht ausschließlich lokal** auf dem Endgerät gespeichert werden.

## Warum das wichtig ist

Endgeräte werden im Rahmen von Wartung, Austausch oder Neuinstallation
regelmäßig zurückgesetzt oder gelöscht. Was nur lokal auf dem Gerät lag, ist
danach weg – ohne Absicht, aber unwiderruflich.

<Bildplatzhalter beschreibung="Schaubild: lokale Speicherung (Risiko) gegenüber Netzlaufwerk (sicher)" />

## Wo Sie wichtige Daten ablegen sollten

Speichern Sie wichtige Daten daher auf einem der folgenden Wege:

- auf den bereitgestellten **persönlichen Netzlaufwerken**, oder
- auf einem **USB-Stick**.

:::tip[Faustregel]
Alles, was Sie nicht verlieren möchten, gehört nicht ausschließlich auf das
lokale Gerät. Wenn Sie unsicher sind, welches Netzlaufwerk für Sie das richtige
ist, fragen Sie einfach per [Ticket](../support/ticket-erstellen.mdx) nach.
:::
